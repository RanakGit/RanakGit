## About

I’m interested in applying computational methods to biological and clinical
questions. My projects span cancer biomarker analysis, NGS variant calling,
protein structure exploration, cheminformatics, and interactive data apps.

I value **reproducibility, clear documentation, and responsible interpretation**
of scientific results.
